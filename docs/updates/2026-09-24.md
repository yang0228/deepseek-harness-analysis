## 主要结论变化

| 主题 | 原基线描述 | 本次修正 |
|---|---|---|
| Desktop | 私有 Host 的管道传输，无应用 Web 端口 | Electron Node 模式启动 Host，复用 Profile runner 与完整 Web 应用；认证 Web Host 默认 `19387`，Node IPC 负责启动与生命周期 |
| 热重载 | Profile 的 `patchReload: live / startup` 字段 | 字段已删除；YAML 中是否组合 `dsh-hmr` 决定配置重载 |
| Agent Preset | 目录扫描、`preset.yml`、standing generation | `dsh-agent-preset` 插件行声明；registry 管理 revision 与引用，最后引用释放后回收退休树，重启解析当前同名定义 |
| Fork | 仅可从已完成 Turn 的前缀分叉 | 支持未结束前缀，fork seed 补齐未结算工具及 Step/Turn；补齐不证明原执行完成 |
| Session v4 | v2/v3 结构与迁移 | 结构化角色、来源与新增相邻迁移；`developer/message` 的存储词汇不等于模型适配器端到端支持 |
| 工具结果 | 直接进入 post-execute policy | 补充 `projectContent` 在 policy 前、`finalizeContent` 在 policy 后；PTC 图片上下文使用 `ptc-mode` 来源 |
| Windows Sandbox | 旧 Everyone 限制描述 | 当前限制为 hard link、未约束读取与 AppContainer ACL 兼容性；仍报告 `partial` |
| Office / Workflow | 能力矩阵缺项、以同步工作流为主 | 新增 Office Skills 与运行时查询的组合归属；说明后台 Job、持久生命周期与瞬时进度的区别 |
