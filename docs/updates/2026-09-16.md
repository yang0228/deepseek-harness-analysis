## 主要结论变化

| 主题 | 旧手册描述 | 当前分析 |
|---|---|---|
| Desktop | 只围绕 CLI Profile 描述应用启动 | 新增 Electron / Node Host、管道与 `dsh-app://`；不误计为第六个 CLI 模板 |
| 响应流 | `assistant/chunk` 作为 durable 记录 | `agent/assistant-stream` 是 live；已结算的 `assistant/message` / `assistant/attempt` 内嵌 compact stream |
| 会话格式 | 未展开新格式迁移 | 区分历史格式读取、内存迁移与写入新 generation；不覆盖旧文件 |
| PTC | Worker、忙碌计算时间与旧 `codeRuntime` | `ctx.ptcRuntime`、新 Node 进程、Session 文件策略、elapsed deadline 与独立资源限制 |
| Workflow / Ralph | PTC 保留 engine 与 Ralph | PTC 默认禁用 engine、通用 Workflow tool 与 Ralph；Standard 保留 Workflow、默认禁用 Ralph |
| Minimal | Shell + editor | 单持久 Shell，不再单独提供 `str_replace_editor` |
| Agent Teams | 私有实验包、被发布排除 | 已发布的 opt-in 实验组合；仍不能当作默认已启用 |
| 新能力入口 | 缺少当前组合说明 | 补充 Browser / Computer Use、MCP、Schedule 的归属与启用限制 |

精确结论、限定和源码跨度分别保存在[架构](../02-architecture.md)、[能力矩阵](../03-capabilities.md)、[PTC](../deep-dives/tools-and-ptc.md)、[会话](../deep-dives/session-event-log.md)与[编排](../deep-dives/subagents-goals-workflows.md)章节，不在本页复制第二份 Claim ledger。
