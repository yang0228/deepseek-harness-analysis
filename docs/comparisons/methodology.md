# 比较方法

本页规定 DeepSeek Harness 与外部 Agent 框架、编码 Agent 产品的比较方法。比较保留不同对象的抽象层级，不把它们强行归一，也不把两个对象组混为同一排名。

## 对象分组

框架组包括 LangGraph、AutoGen 和 OpenAI Agents SDK，讨论用于构建 Agent 系统的编程框架。编码 Agent 产品组包括 Claude Code 和 OpenAI Codex，讨论用户直接操作的编码 Agent 产品。两个组分别使用下述标准；组间不作横向排名。

每一行按“已记录事实、官方来源、版本或 commit 与访问日期、DSH 对应项、不可得信息、作者推论”的顺序填写。对象位于不同抽象层级时，行内明确报告该差异，不用推定的共同能力消除差异。

## Agent 框架标准

框架比较固定使用七项标准：组合方式、可替换能力接口、生命周期归属、状态与持久化、工具执行、编排、扩展机制。

| 标准 | 官方事实 | 官方来源 | DSH 对应机制 | 未见官方文档说明 | 作者推论 |
|---|---|---|---|---|---|
| 组合方式 | 记录官方资料明示的组合单位与关系。 | 记录官方一手来源及版本或 commit、访问日期。 | 记录相同问题在 DSH 中对应的机制。 | 仅记录查阅范围内未见说明的信息。 | 明示作者基于所列证据作出的解释。 |

其余六项标准沿用同一列定义；任何单元格都不填写分数，表格也不增加评分列或未公开内部实现列。

## 编码 Agent 产品标准

产品比较固定使用六项标准：工具与 hook 扩展、执行策略、会话恢复、委派、UI 表面、SDK 与自动化访问。

| 标准 | 官方事实 | 官方来源 | DSH 对应表面 | 未见官方文档说明 | 作者推论 |
|---|---|---|---|---|---|
| 工具与 hook 扩展 | 记录官方资料明示的用户可见行为。 | 记录官方一手来源及版本或 commit、访问日期。 | 记录相同问题在 DSH 中对应的用户或集成表面。 | 仅记录查阅范围内未见说明的信息。 | 明示作者基于所列证据作出的解释。 |

其余五项标准沿用同一列定义；任何单元格都不填写分数，表格也不增加评分列或未公开内部实现列。

## 证据分类

每个比较陈述标为“官方事实”“限定事实”“未见官方文档说明”或“作者推论”。官方事实只复述官方文档、官方仓库、规范或第一方 release note 明示的内容；限定事实同时写明适用版本、平台、配置或查阅范围；作者推论与事实分列，不伪装成来源原文。

官方来源记录 publisher、实际 access date，以及来源明确提供的 version 或 repository commit。不可变 GitHub `blob` 或 `tree` URL 中的 40 位 revision 必须与 ledger 的 `commit` 完全相同。离线验证器只检查元数据和本地 Claim 目标，不发起 HTTP 请求；来源是否保持有效且属于第一方由人工复核。

## 缺失信息

“未见官方文档说明”表示在列明的官方资料和访问日期中没有找到足以支撑陈述的说明，不等于产品或框架“不支持”该能力。比较行应记录查阅范围，不能用推测填补空白，也不能依据未公开内部实现建立对等关系。

## 禁止结论

比较不计算分数，不宣布胜者，不产生排名，不把文档比较称为 benchmark，也不推断速度、成本或质量优势。表格不得添加评分、胜负、排名、benchmark 或未公开内部实现列；不同抽象层级必须保留为明确差异。
